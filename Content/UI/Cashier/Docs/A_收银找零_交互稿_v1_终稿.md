## 1. 一屏结构（竖屏线框）

```
┌─────────────────────────┐
│  [⏱ 剩余秒]     [本班分] │  ← 顶栏 HUD（全程）
├─────────────────────────┤
│                         │
│   ① 购物篮 / 扫码区      │  ← 上区 ~40%
│   （商品可点热区）        │
│                         │
├─────────────────────────┤
│   ② 结算板               │  ← 中区 ~25%
│   应收 / 实付            │
│   Scanning：实付＝「？？」 │
│   PayShown+：实付数字揭晓 │
│   MakingChange：另显 Σ   │
├─────────────────────────┤
│   ③ 钱箱                 │  ← 下区 ~35%
│   [¥1] [¥5] [¥10]       │
│   已选面额条 + [确认]     │
└─────────────────────────┘
```

**全局约束**
- 仅点选，无拖拽/长按必选手势（长按可留空）
- 顶栏计时到 0 → 强制进 `ShiftSettle`（打断当前单）
- 局中 **确认后不弹对/错 Toast**；错找只进班末结算页

## 2. 状态机 × 界面

策划状态：`WaitCustomer → Scanning → PayShown → MakingChange → Confirm → NextCustomer`；班末 `ShiftSettle`。

| 状态 | ① 篮/扫码 | ② 结算板 | ③ 钱箱 | 玩家可点 |
|------|-----------|----------|--------|----------|
| WaitCustomer | 空态/顾客入场表现 | 清空或隐藏数字 | 禁用 | **自动来客**（无「下一位」按钮） |
| Scanning | **未扫商品可点**；已扫灰/勾不可再点 | **应收实时累加**；**实付＝弱对比「？？」占位**（不绑真值、不漏到 HUD） | 禁用 | 点未扫商品扫码；**无撤销** |
| PayShown | 锁定（半透/不可点） | 应收保留；**实付数字翻出/淡入并高亮**；**不显示待找零** | **一律启用**钱箱+确认 | 心算后点面额（也可一张不点）再确认；**无正好捷径** |
| MakingChange | 锁定 | 应收/实付 + **已出面额合计 Σ**（仅点数汇总，不暗示对错） | **面额可点**；已选可删；确认始终可点（含 Σ=0） | 点面额或直接确认；局中不揭晓对错 |
| Confirm | 锁定 | 同 MakingChange | 确认中短锁全屏点按 | 无（极短，或并入确认按下） |
| NextCustomer | 清空动画 | 清空 | 清空 | 自动；离场表现**对错同一套** |
| ShiftSettle | 隐藏玩法三区 | — | — | 看结算；回标题/再来一班 |

**统一路径（已定案）**：**不做「正好单」专用 UI/跳过找零**。凡 `PayShown` 后都进钱箱；玩家若认为不用找零，**面额一张不点，直接点确认**（Σ=0）。后台仍用 `C=Pay−S` 校验：Σ==C 为总额正确（含 C=0），否则记错找。

**扫完自动结算（已定案）**：本单全部可扫件变为已扫后，**自动**进 `PayShown`（无「去结算」按钮）→ 同时揭晓实付。

**实付揭晓（已定案）**：`Pay` 后台单生成时已有，但 **Scanning 态 Widget 不绑真值**；仅进 `PayShown` 时下发给 UI。demo **不做递钱动画**，占位「？？」+ 揭晓翻出/淡入即可。

## 3. 分区交互说明

### 3.1 ① 购物篮 / 扫码区

| 元素 | 热区/行为 |
|------|-----------|
| 未扫商品卡 | 点一下 = 扫码入账；短「嘀」；卡变为已扫态（勾/灰） |
| 已扫商品卡 | **灰/勾、不可再点**（挡连点；**demo 不做撤销**） |
| 已扫列表 | 展示品名+价（只读） |
| 扫完流转 | 全部可扫件扫完 → **自动**进 `PayShown`（揭晓实付） |

**反馈**：扫码光/嘀声（出图+音频占位）；已扫态与未扫态对比清晰。

### 3.2 ② 结算板（不帮算待找零｜实付延迟揭晓）

| 字段 | Scanning | PayShown / MakingChange |
|------|----------|-------------------------|
| 应收 S | 已扫合计，实时累加（只读） | 定值只读 |
| 实付 Pay | **弱对比「？？」占位**（虚线框可有；不抢戏；**绝不显示数字**） | **数字翻出/淡入并高亮**（可短「嘀」）；之后只读 |
| 待找零 C | 不显示 | **仍不显示**；玩家自行心算 `Pay−S` |
| 已出面额合计 Σ | 不显示 | **MakingChange 时显示**（操作反馈，**不是标准答案**） |

**禁止**：用颜色/箭头/进度条暗示 Σ 与正确找零的关系（等于变相揭示 C）。  
**禁止**：Scanning 期间任何路径把 `Pay` 真值漏到结算板或顶栏 HUD。  
确认钮：只要钱箱启用即可点（含少找/多找/零找）；局中不弹对错。

### 3.3 ③ 钱箱

| 元素 | 行为 |
|------|------|
| ¥1 / ¥5 / ¥10 | 每点一次追加一张；确认前可反复点 |
| 已选面额条 | 显示如 `10+5+1+1`；点单张可移除；或「清空」一键 |
| 确认 | **Σ≥0 均可点**（含一张不点）；按下后局中无对错弹窗 → 后台按 Σ 与 C 校验记账 → `NextCustomer` |
| 禁用态 | Scanning / WaitCustomer：面额与确认不可点 |

**最少张数**：UI **不强制**最优；班末结算再标「最优单」。可选：确认钮旁淡字「张数 n」（不判对错）。

## 6. 边界 & 与策划对齐

- 确认前改找零 = 不算错单（已选条可改）
- 实付 < 应收：demo 不做，UI 不出现
- 计时到 0：打断当前单；交互上直接进结算（是否记「未完成」按策划）
- 面额集合写死 `{1,5,10}` 三键，不做滑动选面额
- 已扫灰态挡连点；**无撤销扫码**
- Scanning 不暴露 `Pay`；demo 无递钱动画

## 7. PC 输入映射（验收 + 预留 Steam）

**原则**：玩法规则与热区语义不绑死触屏。微信 demo 用点选；PC 验收与后续 Steam 走同一套 **逻辑 Action**（与 @Linsey Enhanced Input 对齐），只换设备绑定。

### 7.1 逻辑 Action（与热区一一对应）

| Action | 触控/鼠标 | 键盘（建议） | 手柄（建议） | 生效状态 |
|--------|-----------|--------------|--------------|----------|
| `ScanItem` | 点未扫商品卡 | 焦点在商品上时 `Space` / `Enter`；或数字键选第 n 件 | A / × | Scanning |
| `AddDenom_1` | 点 ¥1 | `1` | 十字左 | MakingChange（含 PayShown 进钱箱后） |
| `AddDenom_5` | 点 ¥5 | `2` 或 `5` | 十字上 | MakingChange |
| `AddDenom_10` | 点 ¥10 | `3` 或 `0` | 十字右 | MakingChange |
| `RemoveLastDenom` | 点已选 chip / 清空 | `Backspace` | B | MakingChange |
| `Confirm` | 点确认 | `Enter` | A / × | MakingChange（含 Σ=0） |
| `FocusNext` / `FocusPrev` | — | `Tab` / `Shift+Tab`；方向键 | 左摇杆 / 十字键 | 有可聚焦控件时 |
| `OpenSettle` / 再来一班 | 点结算按钮 | `Enter` | A | ShiftSettle |

**demo 不做 `UndoScan`**：无撤销热区、无对应键位，Action 表不收录。

面额三键互斥焦点：手柄用十字 **左=1 / 上=5 / 右=10**，下可绑「清空」。

### 7.2 焦点与可聚焦热区

- 所有可点热区 = **可聚焦控件**（未扫商品卡、面额键、确认、结算主按钮）。
- 焦点态：描边/高亮（@小钰 ART 补悬停+焦点）。
- 鼠标：悬停 ≈ 焦点预览；点击 = 触发 Action。
- 键盘/手柄：只操作当前焦点；`Confirm` 不误触禁用态按钮。
- 状态切换时焦点默认落到该态「主操作」：Scanning→首件未扫商品；MakingChange→¥1；ShiftSettle→再来一班。

### 7.3 布局

- 竖屏三区比例先服务微信；PC 窗口可信箱/居中，**勿把命中写成绝对触摸坐标**。
- 同一 Widget 树接多平台；禁止「仅 Touch」分支才能点到的逻辑。

### 7.4 Demo 验收最小集（PC）

1. 鼠标完整跑完一班（扫码→找零→确认→班末）；确认 Scanning 见「？？」、PayShown 才见实付数字
2. 键盘：数字加面额 + Enter 确认 + Tab 移焦
3. 手柄：焦点移动 + A 确认 + B 删面额
